Yojana Setu
योजना सेतु (Yojana Setu): Bridging the Gap Between Citizens and Government Schemes.

🚀 Vision
Yojana Setu is an information facilitation platform designed to empower Indian citizens by simplifying the landscape of government welfare schemes. We aim to eliminate information asymmetry, offering a single, digital access point where users can discover, understand, and prepare to apply for the benefits they are rightfully entitled to.

Our ultimate goal is to foster a more inclusive society by ensuring that welfare reaches the last mile through seamless digital connectivity.

🛠️ Tech Stack (Full Stack)
This project is built using a modern, scalable architecture focused on performance, type safety, and maintainability.

Frontend: Next.js 16 (App Router), TypeScript, Tailwind CSS, shadcn/ui.

Backend & DB: Supabase (PostgreSQL), Prisma ORM.

Authentication: NextAuth/Auth.js.

AI Services: Google Gen AI SDK (Gemini 1.5), FastAPI.

Other Tools: Recharts (Analytics), Leaflet/OpenStreetMap (Location features).

🌟 Key Features
1. Unified Citizen Dashboard
A dedicated, multi-tab interface designed to prevent cognitive overload. Citizens interact with one focused feature at a time.

Discover Schemes: Instantly view matched, highly relevant recommendations.

My Eligibility Sandbox: Interactive sliders to simulate "What-If" scenarios (e.g., How does increasing my land holding affect my agri-subsidy?).

Application Tracker: Kanban board tracking official application status.

Document Checklist: Personalized list of required documents with readiness tracking.

Scheme Explorer: Searchable, tag-based directory of all schemes.

2. Intelligent Matching Engine
A deterministic backend engine that uses complex logic—not probabilistic AI—to authorize eligibility based on strict scheme rules (age, income, occupation, location, category tags).

3. High-Impact Tech Innovations
Voice-First Search: Multilingual search (Bhashini-style) allowing users to speak in regional languages like Hindi, Punjabi, or Hinglish.

cumulative Benefit Calculator: Prominently displays the total unlocked financial value matched to the user's profile.

CSC-Friendly Export: 1-Click WhatsApp or PDF checklist export for easy printing at Common Service Centres
